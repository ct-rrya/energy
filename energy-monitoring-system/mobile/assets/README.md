# Mobile App Assets

## Required Assets (Not Included)

The following assets need to be created before building the mobile app:

### App Icon
- **File:** `icon.png`
- **Size:** 1024x1024 pixels
- **Format:** PNG with transparency
- **Purpose:** App icon for iOS and Android

### Splash Screen
- **File:** `splash.png`
- **Size:** 2048x2048 pixels
- **Format:** PNG
- **Background:** #0A2947 (EcoStep dark blue)
- **Purpose:** Launch screen

### Android Adaptive Icon
- **File:** `adaptive-icon.png`
- **Size:** 1024x1024 pixels
- **Format:** PNG with transparency
- **Purpose:** Android adaptive icon foreground

### Web Favicon
- **File:** `favicon.png`
- **Size:** 48x48 pixels
- **Format:** PNG
- **Purpose:** Web version favicon

## Placeholder Notice

Phase 1 uses default Expo placeholders. Replace these files with actual EcoStep branding assets before production deployment.

## Design Guidelines

- Use EcoStep brand colors:
  - Primary: #0A2947 (Dark blue)
  - Secondary: #2FBF71 (Green)
  - Background: #F5F7FA (Light gray)
- Maintain consistent styling with web frontend
- Ensure icons are clear at small sizes (iOS requires 1024x1024)
