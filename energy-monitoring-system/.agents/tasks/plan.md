**Decision:** Mobile does NOT need to replicate these full charts. The task requires "phone-optimized interaction patterns" — mobile can show simplified chart views or omit charts entirely in favor of metric cards. The desktop layout is too complex for mobile screens.

### 5. Dashboard Metrics API Response Shape
**Backend:** `src\dashboard\dashboard.controller.ts` → `GET /api/dashboard/metrics`

**Response Structure:**
```typescript
{
  success: true,
  data: {
    dailyEnergy: number,           // kWh, today's energy
    activeSensors: number,
    totalSensors: number,
    totalReadings: number,
    lastReadingAt: string,         // ISO timestamp
    lastReadingVoltage: number,    // V
    lastReadingCurrent: number,    // A
    lastReadingPower: number,      // W (NOT mW!)
    lastReadingStepCount: number,
    lastReadingSensorId: string,
    todayTotalSteps: number,       // NEW in Phase 3
    aiInsight?: string             // NEW in Phase 3, optional
  }
}
```

**Key Finding:** Backend returns `lastReadingPower` in **Watts (W)**, but desktop displays power in **milliwatts (mW)** by multiplying by 1000 in the component logic.

## Appendix: Key Backend API Endpoints

### Dashboard Metrics (Primary Endpoint)
- **Endpoint:** `GET /api/dashboard/metrics`
- **Auth:** Public
- **Response:**
  ```json
  {
    "success": true,
    "data": {
      "dailyEnergy": 0.000012,
      "activeSensors": 1,
      "totalSensors": 1,
      "totalReadings": 25,
      "lastReadingAt": "2026-10-13T10:30:00.000Z",
      "lastReadingVoltage": 5.2,
      "lastReadingCurrent": 0.000073,
      "lastReadingPower": 0.000377,
      "lastReadingStepCount": 6,
      "lastReadingSensorId": "abc123",
      "todayTotalSteps": 42,
      "aiInsight": "Power output steady, 12% above baseline"
    }
  }
  ```

### Analytics Time-Series (For Future Charts)
- **Endpoint:** `GET /api/analytics/time-series`
- **Query Params:** `metric` (power|voltage|current|energy|steps), `granularity` (hour|day|week|month), `startDate`, `endDate`
- **Auth:** Public
- **Use:** Desktop uses for charts. Mobile may use in future, not required for Phase 3.

### Historical Analysis (AI Insights)
- **Endpoint:** `POST /api/analytics/historical-analysis`
- **Body:** `{ period: "last7days" | "last30days" | "last90days" }`
- **Auth:** Public
- **Response:** AI-generated historical insights + structured metrics
- **Use:** Desktop has analytics page. Mobile can add this feature in future.
