## Changes Implemented

### ✅ FEAT-001: Hero Power Card Component

**New Component Created:**
- `mobile/src/components/dashboard/HeroPowerCard.tsx`

**Features Implemented:**
- Displays current power output in **milliwatts (mW)** as primary KPI
- Converts power from Watts (backend) to milliwatts (display): `power_mW = power_W × 1000`
- Shows power with 4 decimal precision: `0.3770 mW` for small values
- Amber color scheme (`#F59E0B`) to distinguish from energy card (green)
- Displays AI insights when available with amber-tinted background
- Loading state with ActivityIndicator
- Error state with retry button
- Null/undefined handling with "--" placeholder
- Matches desktop behavior while using mobile-native components

**Source Reference:**
- Desktop: `frontend/src/features/dashboard/components/HeroPowerCard.tsx`
- Mobile adaptation: React Native components, vertical layout, touch-optimized

```

  ↓
Response: { power: 0.000377 } (Watts)
  ↓
Mobile: reading?.power
  ↓
HeroPowerCard: powerValue * 1000
  ↓
Display: "0.3770 mW"
```

  ↓

  ↓
