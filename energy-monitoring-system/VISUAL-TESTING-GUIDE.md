# Visual Testing Guide - Chart Responsive Layout

## Quick Visual Verification Checklist

### 1. Open Browser DevTools
- Press F12 or Right-click → Inspect
- Click the Device Toolbar icon (mobile/tablet icon)
- Or press Ctrl+Shift+M (Windows) / Cmd+Shift+M (Mac)

### 2. Test Each Breakpoint

#### 320px (Smallest Mobile)
1. Set viewport to 320 x 568
2. Navigate to Dashboard → Analytics Charts
3. **Expected Result:**
   ```
   ┌───────────────────────┐
   │ Power Generation      │
   │ Real-time power...    │
   │                       │
   │ [Today][7D][30D]     │ ← 3 equal buttons, full width
   │                       │
   │ [Chart displays here] │
   └───────────────────────┘
   ```
4. ✅ Check:
   - [ ] Title on one line or wrapped naturally
   - [ ] Selector below title
   - [ ] All 3 buttons visible and equal width
   - [ ] No horizontal scrollbar on page
   - [ ] Buttons don't overflow card

#### 375px (iPhone Standard)
1. Select "iPhone SE" or set 375 x 667
2. **Expected Result:** Same layout as 320px but more comfortable spacing
3. ✅ Check:
   - [ ] More padding visible
   - [ ] Buttons slightly larger
   - [ ] Still no horizontal overflow

#### 412px (Android Standard)
1. Select "Pixel 5" or set 412 x 915
2. **Expected Result:** Still vertical layout, comfortable button sizes
3. ✅ Check:
   - [ ] Layout remains vertical
   - [ ] Adequate white space
   - [ ] Touch targets feel comfortable

#### 640px (Breakpoint Transition)
1. Set viewport to 640 x 480
2. **Expected Result:** Layout switches to horizontal
   ```
   ┌────────────────────────────────────────┐
   │ Power Generation     [Today][7D][30D] │ ← Selector on right
   │ Real-time power...                    │
   └────────────────────────────────────────┘
   ```
3. ✅ Check:
   - [ ] Title and selector on same row
   - [ ] Proper spacing between elements
   - [ ] Still no overflow

#### 768px (iPad)
1. Select "iPad Mini" or set 768 x 1024
2. **Expected Result:** Full horizontal desktop layout
3. ✅ Check:
   - [ ] Desktop appearance fully active
   - [ ] Larger padding visible
   - [ ] Selector aligned to right

#### 1920px (Desktop)
1. Set viewport to 1920 x 1080
2. **Expected Result:** Full desktop appearance unchanged
3. ✅ Check:
   - [ ] Layout identical to before the fix
   - [ ] No visual regressions

### 3. Test Both Charts
Repeat the above for:
- ✅ "Power Generation Over Time" (Today / 7 Days / 30 Days)
- ✅ "Energy Generated by Period" (Hourly / Daily / Weekly)

### 4. Interaction Testing

#### Click Each Button
1. Click "Today" → should highlight with green background
2. Click "7 Days" → should switch highlight
3. Click "30 Days" → should switch highlight
4. **Verify at 320px:**
   - [ ] Easy to tap each button
   - [ ] Clear visual feedback
   - [ ] No accidental mis-taps

#### Test Scrolling
1. At 320px viewport
2. Scroll down the page
3. ✅ Check:
   - [ ] Only vertical scrolling
   - [ ] No horizontal scrollbar appears
   - [ ] Content stays within bounds

### 5. Empty State Testing
1. If charts show "No data available"
2. ✅ Check at 320px:
   - [ ] Empty state icon centered
   - [ ] Text centered and wrapped
   - [ ] Message fully visible
   - [ ] No clipping

### 6. Theme Testing
1. Toggle between Light/Dark mode
2. ✅ Check at 320px:
   - [ ] Buttons remain visible
   - [ ] Selected state clear in both themes
   - [ ] Colors appropriate for theme

### 7. Orientation Testing (Mobile Devices Only)
1. Rotate device to landscape (or simulate)
2. ✅ Check:
   - [ ] Layout adapts appropriately
   - [ ] No overflow in landscape
   - [ ] Chart remains usable

## What Success Looks Like

### ✅ Mobile (320-639px)
- Title and selector stacked vertically
- Selector spans full width of card
- Three equal-width buttons
- Smaller text (text-xs on buttons)
- Reduced padding (px-4, pt-4)
- No horizontal scrolling anywhere

### ✅ Desktop (640px+)
- Title and selector on same row
- Selector aligned to right
- Buttons normal size
- Normal text (text-sm on buttons)
- Full padding (px-6, pt-6)
- Identical to original desktop design

## Troubleshooting

### If selector still overflows:
1. Hard refresh: Ctrl+Shift+R (Windows) / Cmd+Shift+R (Mac)
2. Clear cache and reload
3. Verify you're testing the built version (npm run build && npm run preview)

### If layout doesn't change at 640px:
1. Check if Tailwind sm: breakpoint is working
2. Inspect element in DevTools
3. Verify classes applied: `flex-col sm:flex-row`

### If buttons look wrong:
1. Check if all three charts updated
2. Verify `w-full` and `flex-1` classes present
3. Check responsive padding: `px-3 sm:px-4`
