## How to Test

### Step 1: Start the Backend
```bash
npm run start:dev
```

### Step 2: Start the Frontend
```bash
cd frontend
npm run dev
```

### Step 3: Generate a Test Report

1. **Login** to the dashboard (use admin credentials)
2. **Navigate to Reports** page
3. **Click "+ Generate Report"**
4. **Select Report Type:**
   - Energy Monitoring
   - Historical Analytics
   - System Diagnostics
   - System Summary
5. **Configure Report:**
   - Start Date: Sep 1, 2026
   - End Date: Sep 19, 2026
   - Select sections (checkboxes)
   - Choose format: PDF or CSV
6. **Click "Generate Report"**

### Step 4: View Generated Report

The report will appear in the reports list with:
- ✅ File name
- ✅ Report type
- ✅ Date range
- ✅ Format badge
- ✅ Actions (View, Download, Delete)

### Step 5: Download and Open

1. Click the **Download** button (or View then Download)
2. Open the PDF/Excel file
3. You'll see the **professionally formatted report**
4. If no data: "No Data Available" message
5. If with data: Full metrics, charts, and analysis

## Report Types Explained

### 1. Energy Monitoring Report
**What it shows:**
- Total energy generated
- Average and peak power
- Voltage and current measurements
- Step activity (if configured)
- Energy generation charts

**Sections (configurable):**
- ☑ Energy Summary
- ☑ Voltage
- ☑ Current
- ☑ Step Activity
- ☑ Energy Chart

**Best for:** Daily/weekly energy monitoring

---

### 2. Historical Analytics Report
**What it shows:**
- Historical trends over time
- Voltage trend analysis
- Current trend analysis
- Energy patterns
- Aggregated data (hourly/daily/weekly)

**Configuration:**
- **Metrics:** Voltage, Current, Energy
- **Aggregation:** Hourly, Daily, or Weekly
- **Charts:** Time-series visualizations

**Best for:** Long-term performance analysis

---

### 3. System Diagnostics Report
**What it shows:**
- Diagnostic test results
- Expected vs actual energy output
- Performance percentage
- System health status
- Historical diagnostic records

**Sections:**
- ☑ Diagnostic History
- ☑ Expected vs Actual Energy
- ☑ Performance Results

**Best for:** System health checks and troubleshooting

---

### 4. System Summary Report
**What it shows:**
- Combined overview of all EcoStep data
- Energy summary
- Electrical measurements
- Historical analytics snapshot
- Diagnostic summary
- Step activity

**Sections:** All of the above combined

**Best for:** Comprehensive system overview

## Troubleshooting

### "No Data Available" in all reports
**This is expected!** Until you have real IoT telemetry data:
- Reports will show zero values
- "No Data Available" message will appear
- Structure and layout are still visible
- This lets you see how reports will look

### Backend error: "No module 'pdfkit'"
```bash
npm install pdfkit
```

### Backend error: "No module 'exceljs'"
```bash
npm install exceljs
```

### Report generation hangs
- Check backend logs: `npm run start:dev`
- Verify uploads directory exists: `/uploads/reports/`
- Check file permissions

### Report preview not showing
- Verify report was generated
- Check browser console for errors
- Ensure modal is not blocked
