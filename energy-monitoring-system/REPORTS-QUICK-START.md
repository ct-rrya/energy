# Reports Module - Quick Start Guide

**Quick reference for generating and managing energy reports**

---

## 🚀 Generate a Report

### Monthly PDF Report
```bash
POST /api/reports/generate
Authorization: Bearer <jwt-token>
Content-Type: application/json

{
  "type": "monthly",
  "format": "pdf",
  "year": 2026,
  "month": 7
}
```

### Weekly Excel Report
```bash
POST /api/reports/generate
Authorization: Bearer <jwt-token>
Content-Type: application/json

{
  "type": "weekly",
  "format": "excel",
  "year": 2026,
  "month": 7,
  "day": 18
}
```

### Custom Date Range (PDF)
```bash
POST /api/reports/generate
Authorization: Bearer <jwt-token>
Content-Type: application/json

{
  "type": "custom",
  "format": "pdf",
  "startDate": "2026-07-01",
  "endDate": "2026-07-15",
  "electricityRate": 0.15
}
```

## 📋 List Your Reports


### With Filters
```bash

Authorization: Bearer <jwt-token>
```

## 📥 Download a Report

```bash
GET /api/reports/<report-id>/download
Authorization: Bearer <jwt-token>
```

---

## 🗑️ Delete a Report

```bash
DELETE /api/reports/<report-id>
Authorization: Bearer <jwt-token>
```

## 📊 Report Types

| Type | Parameters | Example |
|------|------------|---------|
| **Daily** | year, month, day | Single day: July 18, 2026 |
| **Weekly** | year, month, day | Week of: July 14-20, 2026 |
| **Monthly** | year, month | Full month: July 2026 |
| **Custom** | startDate, endDate | Range: July 1-15, 2026 |

## ⚙️ Configuration

### Default Settings:
- **Electricity Rate**: $0.12/kWh (US average)
- **Retention**: 30 days (auto-delete)
- **Page Size**: A4 (PDF)
- **File Storage**: `./uploads/reports/`

### Custom Electricity Rate:
Add `electricityRate` parameter to any report request:
```json
{
  "type": "monthly",
  "format": "pdf",
  "year": 2026,
  "month": 7,
  "electricityRate": 0.15
}
```

## 🐛 Troubleshooting

### "Unauthorized" Error
➡️ Ensure JWT token is included in Authorization header  
➡️ Format: `Authorization: Bearer <token>`

### "Report not found"
➡️ Report may have expired (30-day retention)  
➡️ Check report ID is correct  
➡️ Ensure you own the report

### "Validation error"
➡️ Check required parameters for report type  
➡️ Daily: year, month, day  
➡️ Weekly: year, month, day  
➡️ Monthly: year, month  
➡️ Custom: startDate, endDate

## 📞 API Reference

### Generate Report
- **Endpoint**: `POST /api/reports/generate`
- **Auth**: Required (JWT)
- **Response**: 201 Created

### List Reports
- **Endpoint**: `GET /api/reports`
- **Auth**: Required (JWT)
- **Query Params**: page, limit, type, format
- **Response**: 200 OK

### Get Report Details
- **Endpoint**: `GET /api/reports/:id`
- **Auth**: Required (JWT)
- **Response**: 200 OK

### Download Report
- **Endpoint**: `GET /api/reports/:id/download`
- **Auth**: Required (JWT)
- **Response**: 200 OK (file stream)

### Delete Report
- **Endpoint**: `DELETE /api/reports/:id`
- **Auth**: Required (JWT)
- **Response**: 200 OK

### Get Available Types
- **Endpoint**: `GET /api/reports/types/available`
- **Auth**: Required (JWT)
- **Response**: 200 OK

---

## 💡 Tips

1. **Generate once, download many**: Reports can be downloaded multiple times
2. **Use filters**: List endpoint supports filtering by type and format
3. **Pagination**: Use `page` and `limit` for large report lists
4. **Custom rates**: Override electricity rate for accurate cost projections
5. **Date formats**: Always use ISO 8601 format (YYYY-MM-DD)
