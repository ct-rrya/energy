# Messenger Bot Commands Reference Card

Quick reference for all available Messenger bot commands in the EcoStep Energy Monitoring System.

---

## 📱 Getting Started

Simply message the bot on Facebook Messenger with any of these commands. Commands are case-insensitive.

**Bot Name:** EcoStep Energy Assistant  
**Trigger:** Send any command below

---

## 🎯 Quick Commands

| Command | What You Get |
|---------|-------------|
| `help` | Full command list with categories |
| `status` | Complete system overview with all metrics |
| `energy` | Current energy generation status |

---

## 📊 Energy Monitoring

### `status`
**Shows:** Complete system overview  
**Includes:**
- Today's energy and power
- This week's totals
- This month's summary
- Peak generation record
- Environmental impact
- Cost savings
- Trend analysis

**Use when:** You want a comprehensive snapshot

---

### `energy`
**Shows:** Current energy generation  
**Includes:**
- Today's energy total
- Current power levels
- Peak power today
- Progress to next milestone

**Use when:** You want quick current stats

---

### `battery`
**Shows:** Battery status information  
**Includes:**
- Battery charge level
- Monitoring status
- Temperature readings
- Power metrics

**Use when:** Checking battery health

---

## 📈 Analytics Commands

### `today`
**Shows:** Full daily report  
**Includes:**
- Total energy generated
- Average power
- Peak and minimum power
- Total readings count

**Use when:** Reviewing today's performance

---

### `week` or `weekly`
**Shows:** Weekly energy summary  
**Includes:**
- Week number and date range
- Total energy and power stats
- Daily breakdown for each day
- Total readings

**Use when:** Checking weekly trends

---

### `month` or `monthly`
**Shows:** Monthly energy report  
**Includes:**
- Month name and year
- Total energy generated
- Power statistics
- Active days count

**Use when:** Monthly performance review

---

### `peak`
**Shows:** Peak generation record  
**Includes:**
- Highest power recorded
- Date and time of peak
- Sensor location details

**Use when:** Finding your best performance

## 🔔 Notifications

### `subscribe`

- Important system alerts

---

### `unsubscribe`

**Use when:** You want to stop automatic messages

## 💡 Pro Tips

### Command Aliases
Many commands have multiple names:
- `week` = `weekly`
- `month` = `monthly`
- `impact` = `environmental` = `environment`
- `savings` = `cost` = `money`
- `help` = `start` = `menu`
- `about` = `info`

### Case Insensitive
All commands work in any case:
- `STATUS` = `status` = `Status`

### Quick Navigation
Every response includes suggestions for related commands:
- "Try 'status' for complete overview"
- "Try 'week' or 'month' for longer periods"

### Empty State Handling
If no data is available yet:
- Commands still respond
- You get helpful explanations
- Bot suggests what to try next

## 📋 Command Categories

### 🔍 **Information Only**
These commands just show data:
- `status`, `energy`, `battery`

- `unsubscribe` - Deactivates notifications
